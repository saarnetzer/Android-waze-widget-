# ווידגט Waze: רכב ⇄ אופנוע

ווידגט לאנדרואיד שבלחיצה אחת מחליף ב-Waze את **סוג הרכב** בין *רכב פרטי* ל*אופנוע* ובחזרה.

## למה צריך שירות נגישות?
ל-Waze אין API, Intent או deep link לשינוי סוג הרכב. לכן האפליקציה משתמשת ב**שירות נגישות**
שלוחץ בשבילך על המסכים: התפריט ← הגדרות ← ניווט ← פרטי הרכב ← סוג הרכב ← פרטי / אופנוע,
ואז חוזר למפה. זה לוקח כ-2–4 שניות ורואים את זה קורה על המסך.

השירות מוגבל ל-`com.waze` בלבד, לא פועל עד שלוחצים על הווידגט, ולא אוסף או שולח שום מידע. אין לאפליקציה הרשאת אינטרנט.

## התקנה
1. הורד את `waze-vehicle-toggle.apk` מ-[Releases](../../releases/latest) (נבנה אוטומטית בכל push ל-`main`).
2. פתח את הקובץ בטלפון ואשר "התקנה ממקורות לא ידועים".
3. פתח את האפליקציה **Waze רכב/אופנוע** ← "פתח הגדרות נגישות" ← הפעל את השירות.
   - באנדרואיד 13+ ייתכן שתופיע הודעת "הגדרה מוגבלת". במקרה כזה: הגדרות ← אפליקציות ← Waze רכב/אופנוע ← ⋮ ← "אפשר הגדרות מוגבלות", ואז נסה שוב.
4. הוסף את הווידגט למסך הבית (לחיצה ארוכה על המסך ← ווידגטים).
5. באפליקציה, סמן מה המצב הנוכחי ב-Waze (רכב / אופנוע). מכאן הווידגט יעקוב לבד.

## עברית ואנגלית
השירות עובד גם כש-Waze בעברית וגם כשהוא באנגלית, ואפשר לעבור בין השפות בלי לשנות שום הגדרה. כל שלב מחפש את הניסוחים בשתי השפות.
ההשוואה מתעלמת מה' הידיעה ("סוג הרכב" = "סוג רכב"), ממקפים וסימני כיווניות, מניקוד ומהבדלי אותיות גדולות וקטנות.

## אם זה נתקע
Waze משנה מדי פעם את הניסוחים במסכים. במקרה כזה:
1. פתח את האפליקציה ובדוק את **יומן הריצה האחרונה**. הוא מראה באיזה שלב זה נתקע ואת כל הטקסטים שהיו על המסך.
2. העתק את הטקסט המדויק של הכפתור שהיה צריך ללחוץ עליו, והוסף אותו בשדה המתאים תחת **טקסטים לזיהוי**.

השירות מחפש תמיד את השלב **הרחוק ביותר** שמופיע על המסך, כך שאם Waze מאחד או מדלג על מסכים, זה עדיין יעבוד.
אם הרשימה ארוכה הוא גם גולל כדי למצוא את מה שצריך.

## מפתח חתימה קבוע
ה-Action חותם את ה-APK במפתח קבוע ששמור בסודות של ה-repo (Settings ← Secrets and variables ← Actions):
- `SIGNING_KEYSTORE_BASE64`: קובץ ה-keystore בקידוד base64
- `SIGNING_KEYSTORE_PASSWORD`: הסיסמה (alias: `wazetoggle`)

ככה כל גרסה חדשה מותקנת מעל הקודמת, בלי להסיר את האפליקציה ובלי להפעיל מחדש את הנגישות.
אם הסודות לא מוגדרים, ה-APK נחתם במפתח זמני ומופיעה אזהרה ב-build.
**שמור עותק של ה-keystore.** אם הוא אובד, צריך ליצור מפתח חדש ולהתקין מחדש פעם אחת.

## בנייה מקומית
```
./gradlew assembleDebug
```
דרוש JDK 17 ומעלה ו-Android SDK 34.
